### 三、甲方尚未出手但极可能发动的“降维打击”（预判3大杀招）

#### ▶ 杀招1：**股东代表诉讼反制**（最阴狠）
- **操作路径**：甲方以“吉麟损害公司利益”为由，**代博凯升华起诉陈靖**  
- **指控焦点**：  
  ✓ 擅自使用公司公章签署吉麟关联合同（查用印登记簿）；  
  ✓ 将博凯升华客户资源导入吉麟体系（调取邮箱、CRM系统日志）；  
  ✓ 虚构研发费用套取资金（比对吉麟同期采购发票）  
- **杀伤力**：一旦立案，立即冻结陈靖个人账户，迫使其在薪酬案中让步；且刑事报案（职务侵占）同步推进，制造“涉嫌犯罪”舆论压力。

#### ▶ 杀招2：**对隆发股东的精准策反**（最致命）
- **操作路径**：向乙方（隆发）释放两大诱饵：  
  ✓ **经济诱饵**：承诺“若支持甲方重组方案，40%股权可溢价20%转让给集团”；  
  ✓ **政治诱饵**：“协助处理吉麟纠纷，可获集团推荐进入郑州某国企混改项目董事会”。  
- **杀伤力**：直接瓦解我方“董事会1票+股东会10%”的全部博弈基础；隆发一旦书面声明“支持董事长紧急处置权”，我方所有决议效力主张将彻底破产。

#### ▶ 杀招3：**行政举报组合拳**（最窒息）
- **举报对象**：佛山吉麟（陈靖实控） + 博凯升华（双重主体）  
- **举报事由**：  
  ✓ 吉麟：虚开增值税专用发票（针对“利润分红购买股权”条款，主张其实为借贷资金）；  
  ✓ 博凯升华：未按时申报社保（利用2月欠薪事实）→触发人社局稽查→顺藤摸瓜查账；  
  ✓ 双方：隐瞒关联交易（吉麟向博凯升华销售环保材料价格畸高）→税务稽查立案。  
- **杀伤力**：以行政手段瘫痪我方核心企业，远超民事诉讼周期与威慑力；且稽查结论可直接成为民事案证据。

### 五、给委托方（陈靖）的逆向行动建议（基于对手思维）

> **记住：甲方不怕你告它违法，怕你让它失去控制权。所有行动必须围绕“重建治理合法性”展开。**

1. **立即停止一切“个人维权”叙事**  
   → 将“追讨工资”转化为“为全体员工主张生存权”，联合被欠薪员工共同向郑州人社局提交《集体欠薪投诉书》，同步抄送市委督查室。**目的：把个案升格为社会稳定事件，剥夺甲方“内部事务”话术空间。**

2. **闪电启动“董事会决议效力确认之诉”**（非股东会）  
   → 仅起诉3月11日“否定停业”的董事会决议有效。**理由：** 董事会是法定决策机构，决议有完整签到、表决记录、录音（需立即公证），而甲方无法证明存在法定撤销事由。**胜诉即宣告董事长3月6日、3月23日行为全部无效，为后续追究其赔偿扫清障碍。**

3. **向隆发股东发出《致乙方股东的公开信》（附公证）**  
   → 不谈利益，只列事实：“3月11日董事会三方签字确认继续经营；3月17日股东会您亲口说‘支持陈总带队突围’；现甲方单方毁约，请您选择：是做守约者，还是背信者？” **目的：在隆发决策层制造道德压力，阻断策反可能。**

4. **对“46万押金转货款”启动刑事自诉准备**  
   → 立即委托会计师事务所出具《专项审计意见》，证明该笔款项转移未经任何审批流程、未计入应收账款、直接冲抵甲方关联方货款。**这不是民事纠纷，是挪用资金罪线索——用刑事责任倒逼甲方回归谈判桌。**

### 六、结语：甲方真正的恐惧是什么？

> **他们不怕输掉一场官司，怕的是：**  
> **——你让郑州市场监管局认定“博凯升华已无实际经营场所、无从业人员、无主营业务”，从而启动吊销营业执照行政程序；**  
> **——你让隆发股东在股东会上当场质问：“甲方实缴的600万，到底进了谁的账户？”并要求查阅全部银行流水；**  
> **——你把“董事长雷天乾”三个字，从集团官网高管名录中永久删除。**  

**这场战争，从来不在法庭上决胜负，而在谁先让对方的权力根基，在阳光下寸寸崩塌。**  
请务必以“重建公司存续”为最高目标，所有法律动作皆服务于**恢复经营能力、锁定控制权证据、瓦解甲方同盟**——这，才是击穿对方所有防御的唯一路径。
