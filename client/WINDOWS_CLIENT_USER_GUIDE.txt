法律大模型 Windows 客户端使用说明书
版本：v2.1.0

一、客户端是什么

Windows 客户端是“法律大模型”的桌面入口。安装后会在 Windows 桌面窗口中打开系统，不需要每次手动输入网址。

当前版本默认连接服务器：
https://fl.jilinpc.com

客户端本身不替代律师，也不承诺任何法律结果。系统用于整理事实、保全证据、识别风险、生成待核验草稿和行动清单。

二、适合谁使用

1. 律所
   用于案件工作底稿、证据整理、文书草稿、风险分析和团队协作。

2. 企业
   用于合同风险、应收账款、劳动用工、客户供应商争议、制度合规和律师协作。企业端目标是让任何企业拥有靠谱的法律顾问感。

3. 个人
   用于法律问题整理、事实时间线、证据保全、沟通协商、投诉调解和文书草稿。个人端目标是让普通人在法律问题面前有可靠后盾。

三、安装步骤

1. 解压下载的 LegalAI-Windows-Client-v2.1.0.zip。
2. 双击 LegalAI-Setup-v2.1.0.exe。
3. 按安装向导提示完成安装。
4. 如 Windows SmartScreen 提示风险，请确认文件来源为官方系统下载入口后，选择“仍要运行”。
5. 安装完成后，可以从桌面快捷方式或开始菜单启动。

四、首次使用

1. 打开客户端。
2. 点击注册或登录。
3. 注册时选择账户类型：
   - 律所：进入法律案件 AI 工作底稿系统。
   - 企业：进入企业法律顾问工作台。
   - 个人：进入个人法律后盾。
4. 按页面提示完成手机号验证和账户创建。

五、常见使用路径

律所用户：
1. 新建案件。
2. 上传证据。
3. 整理当事人、诉求和时间线。
4. 生成待核验文书草稿。
5. 由律师或专业人员复核后再提交或对外发送。

企业用户：
1. 创建合同、欠款、用工或客户供应商争议事项。
2. 上传合同、聊天记录、对账单、发票、付款凭证等材料。
3. 查看风险提示和材料缺口。
4. 生成给内部负责人或外部律师的摘要。

个人用户：
1. 先描述遇到的事，不需要使用专业术语。
2. 说明最担心的问题。
3. 上传关键凭证，如聊天记录、转账记录、合同、照片、录音、快递单、投诉记录。
4. 查看下一步行动清单。
5. 对高风险、紧急期限或复杂纠纷，及时寻求线下专业帮助。

六、安全与边界提示

1. 系统输出是辅助材料，不是最终法律意见。
2. 文书、函件、投诉材料和诉讼材料均应人工核验后再使用。
3. 不要上传与当前法律事务无关的敏感隐私材料。
4. 不要把系统输出当作胜诉承诺、合规承诺或代理意见。
5. 遇到人身安全、财产转移、诉讼期限、劳动仲裁时效等紧急事项，应优先采取现实保护措施。

七、常见问题

问：客户端打开后是网页吗？
答：客户端是桌面窗口形式，默认连接服务器上的最新系统页面。因此服务器更新后，客户端通常无需重新安装即可看到新功能。

问：为什么下载包里有说明书？
答：安装程序用于安装客户端，说明书用于帮助用户理解注册类型、使用路径和法律 AI 的边界。

问：企业和个人页面是否需要单独安装新客户端？
答：通常不需要。当前客户端连接服务器，企业和个人页面由服务器统一更新。

问：无法打开客户端怎么办？
答：请确认网络可以访问 https://fl.jilinpc.com。如果浏览器也无法访问，请检查网络、防火墙或稍后重试。

问：我可以把 AI 生成的文书直接提交吗？
答：不建议。所有文书草稿都应逐项核验事实、证据、金额、主体、日期、管辖、签章和法律依据后再使用。
