# 企业端与个人端页面落地计划

## 产品定位

律所端继续定位为“可复核的法律案件 AI 工作底稿系统”。

企业端定位为“让任何企业拥有靠谱的法律顾问”，重点不是替企业作出最终法律判断，而是把经营中的合同、用工、回款、供应商、客户争议和合规问题持续纳入风险识别、材料留痕和行动跟踪。

个人端定位为“普通人的法律后盾”，重点不是把用户推给律师，而是在用户彷徨、无助和信息不对称时，先把人扶住：稳定处境、厘清事实、保全证据、提示风险、陪他走出第一步。

## 第一阶段：注册后的专属首页

目标：注册页已区分“律所 / 企业 / 个人”，登录后首页也必须对应不同心智。

企业首页：
- 标题：企业法律顾问工作台
- 核心模块：合同风险、应收账款、用工风险、客户供应商争议、制度合规、外部律师协作
- 今日行动：上传合同或函件、整理欠款材料、创建用工风险事项、生成给律师的摘要
- 关键提示：材料先留痕，结论待核验，高风险事项建议转专业律师

个人首页：
- 标题：个人法律后盾
- 核心模块：紧急风险、事实时间线、证据保全、沟通协商、投诉调解、文书草稿
- 今日行动：描述遇到的事、列出最担心的问题、上传关键凭证、获得下一步清单
- 关键提示：不制造焦虑，不承诺结果，先帮用户看清楚并稳住行动

## 第二阶段：专属创建入口

企业端新增“法律事项”创建入口：
- 合同审查
- 欠款催收
- 劳动用工
- 客户供应商纠纷
- 印章授权与审批
- 数据与知识产权风险

个人端新增“法律问题”创建入口：
- 欠款借贷
- 劳动工资
- 租房居住
- 消费维权
- 婚姻家事
- 交通事故
- 人身侵权

当前落地状态：
- 企业工作台的“上传合同或函件 / 整理欠款材料 / 创建用工风险事项”会带模板参数进入新建页。
- 企业租户进入新建页时显示“新建法律事项”，模板、字段、证据提示和提交按钮均采用企业法律顾问口径。
- 个人工作台的“描述遇到的事 / 列出最担心的问题”会带模板参数进入新建页。
- 个人租户进入新建页时显示“新建法律问题”，模板、字段、证据提示和提交按钮均采用普通人法律后盾口径。

## 第三阶段：专属问答与工作流

企业端问题流：
- 公司基本信息
- 合同或争议对象
- 金额与期限
- 已有证据
- 已采取行动
- 需要内部处理还是外部律师协作

个人端问题流：
- 发生了什么
- 现在最担心什么
- 是否有紧急期限或安全风险
- 有哪些聊天、转账、合同、照片、录音、投诉记录
- 今天能做的第一步
- 什么时候必须寻求线下律师或公权力帮助

当前落地状态：
- 企业租户新建法律事项时，已出现“企业法律顾问第一轮问题”，覆盖公司基本信息、相对方、金额期限、已有证据、已采取行动和处理目标。
- 个人租户新建法律问题时，已出现“个人法律后盾第一轮问题”，覆盖发生事实、主要担心、紧急风险、已有材料、今天第一步和线下求助边界。
- 第一轮问答会随创建请求整理进事项/问题描述，后续案件概览、AI 助手、报告和文书模块可继续复用该底稿。

## 第四阶段：差异化导航和权限

企业端导航应减少“诉讼攻防”表达，突出：
- 法律事项
- 合同与函件
- 回款与催收
- 用工与合规
- 风险台账
- 律师协作

个人端导航应减少专业门槛，突出：
- 我的法律问题
- 下一步
- 证据保全
- 沟通记录
- 文书草稿
- 求助清单

当前落地状态：
- 桌面侧边栏和移动侧边栏会按租户类型显示“案件管理 / 法律事项 / 我的法律问题”等不同导航。
- 企业端将证据、风险、时间线、函件、执行等模块显示为“材料留痕、风险识别、期限台账、合同与函件、回款跟踪”等经营场景语言。
- 个人端将证据、风险、时间线、函件、执行等模块显示为“证据保全、风险提示、下一步、沟通记录、履行跟踪”等普通用户语言。
- 列表页、空状态、新建按钮、批量操作、详情页头部和概览页基础信息已按租户类型替换显示文案，路由和数据结构保持不变。

## 验收标准

- 企业、个人、律所三类注册后都有明确不同的首页心智。
- 企业页面必须体现“靠谱法律顾问”，不能只复用案件管理。
- 个人页面必须体现“法律后盾”，不能只做律师导流。
- 所有页面继续遵守法律 AI 边界：草稿、核验、风险提示、行动清单，不承诺结果。
- Windows 客户端作为服务器 WebView 入口，必须能访问同一套企业/个人页面；发布时下载入口应指向包含安装程序和使用说明书的 `.zip` 下载包。
- 前端类型检查和生产构建通过。
