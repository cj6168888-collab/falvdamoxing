## 二、技术栈

### 2.1 前端技术栈

| 层级 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 框架 | React | 18+ | UI框架 |
| 语言 | TypeScript | 5.0+ | 类型安全 |
| 构建 | Vite | 5.0+ | 快速构建 |
| 样式 | Tailwind CSS | 3.4+ | 原子化CSS |
| 状态 | Zustand | 4.0+ | 轻量状态管理 |
| 请求 | React Query | 5.0+ | 服务端状态 |
| 路由 | React Router | 6.0+ | 路由管理 |
| 表单 | React Hook Form | 7.0+ | 表单处理 |
| UI组件 | shadcn/ui | latest | 美观组件库 |
| 图表 | Recharts | 2.0+ | 数据可视化 |

### 2.2 后端技术栈

| 层级 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 框架 | FastAPI | 0.110+ | 高性能Web框架 |
| 语言 | Python | 3.11+ | 运行环境 |
| ORM | SQLAlchemy | 2.0+ | 数据库ORM |
| 验证 | Pydantic | 2.0+ | 数据验证 |
| 任务 | Celery | 5.0+ | 异步任务 |
| 缓存 | Redis | 7.0+ | 缓存/会话 |
| WebSocket | FastAPI WebSocket | - | 实时通信 |

### 2.3 数据存储

| 存储 | 技术 | 用途 |
|------|------|------|
| 关系数据库 | SQLite/PostgreSQL | 业务数据 |
| 向量数据库 | ChromaDB | 法律资料检索 |
| 缓存 | Redis | 会话/热点数据 |
| 文件存储 | 本地/OSS | 文书/录音文件 |

### 2.4 AI/ML

| 组件 | 技术 | 说明 |
|------|------|------|
| 本地LLM | Ollama + Gemma | 离线推理 |
| 云端LLM | DashScope + Qwen | 高性能推理 |
| 向量模型 | sentence-transformers | 本地Embedding |
| 路由 | ModelRouter | 智能模型选择 |

## 四、数据流

### 4.1 案件创建流程

```
用户 ──► 前端表单 ──► 验证 ──► API请求 ──► CaseService
                                                    │
                                        ┌───────────┴───────────┐
                                        │                       │
                                        ▼                       ▼
                                  SQLite写入              事件通知
                                  (业务数据)              (可选)
                                        │
                                        ▼
                                  返回结果
                                        │
                                        ▼
                                  前端更新 ──► 页面刷新
```

### 4.2 LLM生成流程

```
用户请求 ──► 前端 ──► /api/llm/generate
                              │
                              ▼
                    ┌─────────────────┐
                    │   API Gateway   │
                    └────────┬────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ ModelRouter    │
                    │ • 分析任务类型  │
                    │ • 检查模型可用性│
                    │ • 选择最优模型  │
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              │              │              │
              ▼              ▼              ▼
        本地Gemma      云端Qwen       缓存结果
              │              │              │
              └──────────────┼──────────────┘
                             │
                             ▼
                    ┌─────────────────┐
                    │ 返回生成结果    │
                    │ + 来源标记      │
                    └─────────────────┘
```
