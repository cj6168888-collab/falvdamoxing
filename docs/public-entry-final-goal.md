# 公共主页与三类注册登录入口最终目标

## 最终目标

把公共入口体系做到可上线、可复用、可收口：

1. 主页清楚表达产品定位：可复核的法律 AI 工作底稿系统。
2. 三类用户入口清晰分流：
   - 律所：可复核的案件 AI 工作底稿。
   - 企业：让任何企业拥有靠谱的法律顾问。
   - 个人：做你的法律后盾，先帮你稳住局面。
3. 三套注册/登录页符合各自心理场景：
   - 律所：专业、高效、团队协作。
   - 企业：经营风险可控、事项留痕、内外部协作。
   - 个人：安定、清楚、尊重、可行动，不做律师导流页。
4. Logo、颜色、组件、文案形成统一品牌系统，后续后台、Windows 客户端和宣传材料可复用。
5. 线上用户能自然完成路径：主页 -> 选择身份 -> 注册/登录 -> 进入对应工作台。

## 终止条件

满足以下条件后，停止继续泛化打磨，进入下一阶段：

1. 路由完成：`/`、`/law-firm`、`/enterprise`、`/personal`、三类 `/login/*`、三类 `/register/*` 均可访问。
2. 文案完成：无乱码、无泛泛 AI 话术、无“个人用户导流律师”的错误表达。
3. 视觉完成：桌面端和移动端无明显拥挤、错位、横向溢出；品牌色、Logo、卡片、按钮风格统一。
4. 功能完成：注册页能正确带入 `tenant_type`，登录后正常进入系统。
5. 资产完成：Logo 方案、首页效果图、三类注册登录效果图、实机截图均保存到项目文档目录。
6. 验证完成：`typecheck`、`build`、桌面/移动浏览器检查、线上 200 检查全部通过。
7. 部署完成：提交、推送、服务器热同步完成，Windows 客户端下载仍正常。
8. 仓库干净：无未提交代码，无临时部署包残留。

## 已知边界

- AI 辅助系统不替代律师和专业判断。
- 个人入口的目标是稳住处境、保存证据、理清风险和下一步，不以转介绍律师为主目标。
- 后续若继续优化，只接受明确缺口：真实 Logo 定稿、注册链路抽测、SEO 文案深化、移动端细节修正。
