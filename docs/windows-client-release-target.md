# Windows 客户端发布目标与终止条件

## 最终目标

Windows 客户端必须作为一个可直接交付给用户的下载包发布，而不是零散安装文件。

下载包名称：

`LegalAI-Windows-Client-v2.1.0.zip`

下载包必须包含：

- `LegalAI-Setup-v2.1.0.exe`：Windows 安装程序。
- `使用说明书.txt`：面向普通用户的安装、登录、企业/个人/律所入口说明、常见问题和安全提示。

客户端下载入口必须出现在登录页和注册页，并指向 zip 包：

`/downloads/LegalAI-Windows-Client-v2.1.0.zip`

客户端运行方式：

- 当前 Windows 客户端是 WebView 桌面壳，默认打开 `https://fl.jilinpc.com`。
- 因此企业端、个人端和律所端页面以服务器最新前端为准。
- 当服务器前端已部署企业/个人首页后，Windows 客户端无需重装即可看到新页面。
- 只有安装程序自身、窗口标题、图标、启动方式或打包依赖变化时，才需要重新构建 `.exe`。

## 终止条件

本阶段任务只有同时满足以下条件才算完成：

1. 仓库内存在面向用户的 Windows 客户端使用说明书源文件。
2. 本地打包脚本能从现有安装程序和说明书生成 `LegalAI-Windows-Client-v2.1.0.zip`。
3. 生成的 zip 包内必须能看到安装程序和 `使用说明书.txt`。
4. 登录页和注册页下载链接必须指向 zip 包，而不是裸 exe 或不存在的 tar.gz。
5. 部署脚本必须在每次前端构建后自动把 zip 包放入 `frontend/dist/downloads/`。
6. 前端类型检查、生产构建和 zip 打包脚本必须通过。
7. 部署到服务器后，`/downloads/LegalAI-Windows-Client-v2.1.0.zip` 必须能被访问，且响应体大小与本地 zip 大小一致或接近。
8. 服务端 `/ready` 和 `/health` 必须正常。
9. 本地工作区无未提交改动、无残留发布 tar 包。

## 后续停止规则

本阶段完成后停止继续扩展 Windows 客户端，不顺手重构客户端构建脚本、不重做安装器、不引入自动更新机制。后续如果要做客户端自动更新、离线模式或本地数据库版，必须另起明确任务。
