### Phase 1.1: 上诉追踪 API

**工时**: 8 小时
**优先级**: P0

#### 已有资源

| `/api/appeal/case/{case_id}/arguments` | POST | 创建上诉论点 |
| `/api/appeal/argument/{argument_id}` | PUT | 更新上诉论点 |
| `/api/appeal/argument/{argument_id}` | DELETE | 删除上诉论点 |
| `/api/appeal/appeal/{appeal_id}/deadlines` | GET | 获取上诉期限 |
| `/api/appeal/appeal/{appeal_id}/deadlines` | POST | 创建上诉期限 |
| `/api/appeal/appeal/{appeal_id}/documents` | GET | 获取上诉材料 |
