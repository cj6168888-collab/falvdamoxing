## 三、前端功能缺陷

### 3.1 P0 高优先级缺陷 (6项)

#### [P0-F001] 可调整面板布局功能不完善

| 属性 | 内容 |
|------|------|
| **文件** | `frontend/src/components/layout/panel-layout.tsx` |
| **问题** | 硬编码 50/50 分割，无拖拽调整功能 |
| **设计要求** | React Flow 可调整面板，支持拖拽、预设模式 (对比/专注/全屏) |
| **影响** | 用户无法自定义布局，影响多模块对比分析体验 |
| **修复方案** | 重写为 react-resizable-panels，添加布局预设和持久化 |
| **预估工时** | 4 小时 |

#### [P0-F002] 文书版本 diff 对比缺失

| 属性 | 内容 |
|------|------|
| **文件** | `frontend/src/components/document/` |
| **问题** | 缺少可视化 diff 组件，无法对比文书版本差异 |
| **设计要求** | 集成 diff-match-patch，可视化高亮，逐行对比 |
| **影响** | 无法对比文书修改，历史版本无法回溯 |
| **修复方案** | 创建 `version-diff.tsx` 组件 |
| **预估工时** | 6 小时 |
