# 法律案件追踪系统 - 完整测试策略与清单

## 测试架构

```
测试金字塔
    /\
   /E2E\          Playwright (浏览器自动化)
  /------\
 / 集成测试 \      Testing Library (组件交互)
/----------\
/ 单元测试  \     Vitest (hooks, utils, stores)
------------
```

## 工具链

| 工具 | 用途 | 命令 |
|------|------|------|
| **Vitest** | 单元测试 | `npm run test` |
| **Vitest Watch** | 开发模式测试 | `npm run test:watch` |
| **Vitest Coverage** | 覆盖率报告 | `npm run test:coverage` |
| **Vitest UI** | 可视化测试界面 | `npm run test:ui` |
| **Playwright** | E2E 测试 | `npm run test:e2e` |
| **Playwright UI** | E2E 可视化 | `npm run test:e2e:ui` |
| **MSW** | API Mock | 自动集成 |
| **Testing Library** | 组件测试 | 集成在 Vitest 中 |

```typescript
test('calls onClick when clicked', async () => {
  const user = userEvent.setup();
  const handleClick = vi.fn();
```

#### 逻辑闭环测试场景

| 场景 | 步骤 | 预期 |
|------|------|------|
| **案件创建到结案** | 创建案件 → 添加当事人 → 上传证据 → 创建文档 → 设置期限 → 更新状态为已结案 | 案件状态正确更新，所有关联数据完整 |
| **证据完整流程** | 上传证据 → 编辑证据 → 关联争议焦点 → 核实证据 → 查看证据图谱 | 证据状态流转正确，图谱显示关联 |
| **文档版本管理** | 创建文档 → 编辑保存 → 查看版本历史 → 比较版本 → 回滚到旧版本 | 版本记录完整，回滚成功 |
| **期限提醒流程** | 创建期限 → 设置提醒 → 模拟时间推进 → 验证提醒触发 → 标记完成 | 提醒按时触发，状态正确更新 |
| **庭审准备流程** | 创建庭审 → 准备提纲 → 添加质证要点 → 模拟庭审记录 → 生成庭审报告 | 庭审数据完整，报告生成正确 |
| **对抗分析流程** | 创建分析 → 添加SWOT → 预测场景 → 生成应对方案 → 导出分析结果 | 分析数据完整，导出成功 |
| **上诉流程** | 创建上诉 → 添加理由 → 准备论据 → 生成上诉状 → 跟踪上诉期限 | 上诉数据完整，期限计算正确 |
| **执行流程** | 申请执行 → 跟踪进度 → 更新里程碑 → 记录执行金额 → 结案 | 执行进度正确，金额累计准确 |

## CI/CD 集成

```yaml
# .github/workflows/test.yml
name: Test
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci
      - run: npm run typecheck
      - run: npm run test:coverage
      - run: npx playwright install --with-deps
      - run: npm run test:e2e
      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: playwright-report
          path: playwright-report/
```

## 测试开发工作流

1. **开发新功能时**
   ```bash
   # 开启监听模式，自动运行相关测试
   npm run test:watch
   ```

2. **提交前**
   ```bash
   # 运行完整测试套件
   npm run test:all
   ```

3. **调试失败测试**
   ```bash
   # 使用可视化界面调试
   npm run test:ui
   # 或 E2E 可视化
   npm run test:e2e:ui
   ```

4. **生成报告**
   ```bash
   # 覆盖率报告
   npm run test:coverage
   # E2E HTML报告
   npm run test:e2e
   # 查看报告: playwright-report/index.html
   ```
